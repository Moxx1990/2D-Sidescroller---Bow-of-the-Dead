# 🏹 Bow of the Dead

A 2D side-scrolling action game built with HTML, CSS and JavaScript.

Help the Samurai survive the wave of zombies by collecting arrows, sake and fighting through the dangerous level in a dark post-apocalyptic world.

## ✨ Features

- 🎮 2D side-scroller gameplay
- 🧟 Zombie enemies
- 🏹 Bow and arrow combat system
- ❤️ Health system
- 🔊 Sound effects and background music
- 🎨 Frame-based animations
- 📱 Responsive design
- 🧠 Object-oriented JavaScript architecture

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Object-Oriented Programming (OOP)

---

## 🎯 Gameplay

- Move through dangerous level
- Defeat zombies using your bow or jump on the enemy
- Collect arrows and sake
- Defeat all enemies to win

---

## ⌨️ Controls

| Key | Action |
|---|---|
| Arrow Left / Right | Move |
| Arrow UP | Jump |
| Space | Shoot Arrow |
